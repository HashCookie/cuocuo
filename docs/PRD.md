# 错错 · 行测错题本 PRD

版本：v1.0 草案  
日期：2026-10-02  
状态：第一版已按本文实现  
工程：`cuocuo`（SwiftUI，已有空工程）  
系统：iOS / iPadOS 27 为主，Mac 27 可编译运行，visionOS 不单独设计

这份文档只覆盖第一版。确认后按文末验收标准实现，不提前做复习推送、云同步和自动生成错因。

---

## 1. 产品一句话

错错是一本放在手机里的行测错题本。错题和错因都用文稿扫描收进来，原件留下，文字识别出来，按四个模块回头翻。

## 2. 给谁用

正在准备公务员、事业单位等行测考试的人。做完一套卷子，把做错的题和自己写下的错因纸页扫进对应模块，过后按模块、错因和关键词再找出来。

一个人使用，数据留在这台设备上。没有账号，没有班级，没有分享社区。

## 3. 问题与原则

纸质错题和错因分散在卷子、草稿纸和笔记本上，按模块回看时对不上。

第一版守这几条：

- 四个模块是信息架构的根，不把别的考试科目做进来。
- 题目和错因都支持文稿扫描、拍照、从相册或文件选入。文稿扫描是首选入口。
- 图片是原件。识别出的文字用来搜索和快速浏览，识别失败不影响保存。
- 错因由用户自己提供（扫描手写分析、拍老师批注，或直接打字）。App 不生成错因。
- 界面用 SwiftUI 和系统组件，跟系统设置、备忘录、文件 App 同一套交互，不自绘一套控件皮肤。

## 4. 范围

### 4.1 第一版要做

- 四个模块：言语理解、判断推理、数量关系、资料分析。
- 新建、查看、编辑、删除一条错题。
- 每条错题包含题目原件和错因原件，两边都能多页。
- 三种收录方式：文稿扫描、拍照、相册或文件。
- 收录后在设备上做中文文字识别，文字可改。
- 错因标签、可选子题型、掌握状态。
- 按模块浏览、搜索、按掌握状态和错因筛选。
- 全部数据存在本机。

### 4.2 第一版不做

- 账号、登录、iCloud、多人协作。
- 自动批改、自动写错因、讲解视频、题库。
- 间隔重复和推送提醒。第一版只记录「未掌握 / 已掌握」。
- 导出 PDF、打印、分享到别的 App。
- 手写批注编辑器。用户在纸上写好再扫描。
- 社区、排行、打卡。

这些留到后续版本，见第 12 节。

## 5. 信息架构

iPhone 用单栏导航。iPad 和 Mac 用系统侧边栏，栏里是「全部」和四个模块。

```text
错错
├── 全部错题
├── 言语理解
├── 判断推理
├── 数量关系
└── 资料分析
    └── 错题列表
        └── 错题详情
            ├── 题目原件与识别文字
            └── 错因原件、识别文字、标签

新建 / 编辑（表单弹层）
搜索（系统搜索栏，可作用于当前模块或全部）
```

底部不做四个 Tab。模块名字较长，侧边栏和首页列表更清晰，也和系统 App 一致。

首页每一行一个模块，右侧是该模块「未掌握」的数量。行内副标题用模块全称：

| 列表标题 | 副标题 | 子题型（选填） |
| --- | --- | --- |
| 言语理解 | 言语理解与表达 | 逻辑填空、片段阅读、语句表达 |
| 判断推理 | 判断推理 | 图形推理、定义判断、类比推理、逻辑判断 |
| 数量关系 | 数量关系 | 数学运算、数字推理 |
| 资料分析 | 资料分析 | 文字资料、表格资料、图形资料、综合资料 |

子题型可以不选。选了之后可筛选，不选不影响保存。

## 6. 一条错题里有什么

一条错题是一次收录的最小单位。资料分析里一张图加后面的题，由用户决定扫成一条还是多条。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 所属模块 | 是 | 四个模块之一。从某个模块里点「新建」时，模块已填好，仍可改。 |
| 子题型 | 否 | 上表中的可选项。 |
| 题目页面 | 是 | 至少一页。顺序可调整。 |
| 题目文字 | 否 | 各页识别结果合并后的文本，用户可改。空着也能保存。 |
| 错因页面 | 条件必填 | 与「错因文字」至少有一个。 |
| 错因文字 | 条件必填 | 识别结果或手打。与错因页面至少有一个。 |
| 错因标签 | 否 | 可多选，可再加一条自定义短标签。 |
| 掌握状态 | 是 | 新建时默认「未掌握」。 |
| 创建时间、修改时间 | 是 | 系统写入。 |

题目页面和错因页面分开存放，详情里分两段展示，不能混在同一叠图里。

### 6.1 错因标签

标签用来筛选，不代替错因原文。各模块在通用标签之外，再提供本组常用项。用户也可以输入一条自定义标签（最多 12 个字）。

通用：审题偏差、知识点盲区、粗心、时间不够、选项比较失误。

| 模块 | 本组标签 |
| --- | --- |
| 言语理解 | 词语辨析不清、语境把握错、主旨概括偏、细节对应错 |
| 判断推理 | 图形规律未识别、定义要点遗漏、类比关系判错、推理形式错误、加强削弱方向反了 |
| 数量关系 | 公式用错、计算错误、条件转化错、未作代入排除 |
| 资料分析 | 读数或单位错误、公式用错、估算比较失误、时间范围看错 |

一条错题可以同时带通用标签和本组标签。筛选时选中的标签按「同时包含」过滤。

### 6.2 掌握状态

- 未掌握：还要再看。
- 已掌握：用户自己标记。详情页和列表滑动操作都能改。

第一版不根据时间自动改状态，也不安排复习日期。

## 7. 收录

题目和错因共用同一套收录能力，界面上是两段独立的「页面」。

### 7.1 三种入口

1. **扫描文稿（首选）**  
   使用系统文稿扫描仪。自动找纸边、拉正、增强对比。一次可扫多页，扫完按页序进入对应段落。适合卷子、草稿纸、笔记本。

2. **拍照**  
   使用系统相机拍一张，收入当前段落。适合已经摊开、不适合走纸边检测的页面。

3. **从相册或文件选入**  
   使用系统照片选择器或文件选择器，可多选图片。不向 App 申请「访问所有照片」权限。

每一页在保存前可以：预览、删除、调整顺序、重新识别这一页。

### 7.2 文字识别

- 每一页扫描、拍照或选入后，在本机识别文字。
- 语言：简体中文和英文。
- 识别结果按页序拼进该段的文字栏，用户可以改。
- 再扫一页时，新文字接在末尾，不覆盖用户已经改过的段落。实现时以「用户是否编辑过」为准：编辑过则只追加新页文字；没编辑过则按当前全部页面重新拼接。
- 图表、图形推理、复杂表格经常识别不全。页面上提示「图片会原样保存，文字用于搜索」。识别失败只在该页标出，不弹阻断对话框。
- 识别过程中，该页显示系统进度指示。用户可以先继续扫下一页。

### 7.3 保存规则

满足以下条件才能点「存储」：

- 已选模块。
- 题目至少一页。
- 错因至少一页，或错因文字去掉空白后还有内容。

未满足时，「存储」不可用，表单相应段落用一句话说明还缺什么。

点「取消」时，若已经扫过页面或写过字，用系统确认对话框询问是否丢弃。

编辑已有错题使用同一张表单，标题改为「编辑错题」。

## 8. 浏览、搜索、删除

### 8.1 列表

- 默认按修改时间新的在前。
- 每一行：模块名（在「全部」里显示）、子题型、题目文字的第一行摘要；没有文字时摘要为「未识别出文字」。右侧是掌握状态。
- 行首用该题第一页题目缩略图。
- 提供系统分段筛选：全部、未掌握、已掌握。
- 提供错因标签菜单筛选，只列出当前结果里真正出现过的标签。
- 左滑：标记掌握状态、删除。删除需系统确认。
- 空列表说明这个模块还没有错题，并提供「扫描一道错题」。

### 8.2 详情

一页里按顺序显示：

1. 标题区：模块、子题型、掌握状态、收录日期。掌握状态用系统开关或按钮当场切换。
2. 题目：横向翻页看原件，下面是题目文字。
3. 错因：同样的原件翻页、错因文字、标签。
4. 工具栏：编辑、删除。

原件用系统缩放查看，双指放大。点某一页可全屏翻看。

### 8.3 搜索

使用导航栏上的系统搜索。搜索范围是题目文字、错因文字、子题型和标签。不搜图片像素。

从首页进入搜索时查全部模块。从某一模块进入时默认只查这一模块，搜索栏提供范围切换：「当前模块」「全部模块」。

没有匹配时显示空状态，不给出推荐题。

## 9. 页面与系统组件

只使用系统组件和 SF Symbols。颜色用系统语义色和工程里已有的 AccentColor，不单独做品牌色板。动态字体、深色模式、粗体文字跟随系统。

| 界面 | 组件 |
| --- | --- |
| 模块首页 | `NavigationStack`，`List`，模块行用 `Label` |
| iPad / Mac | `NavigationSplitView`，侧边栏为模块 |
| 错题列表 | `List`，`.searchable`，`picker` 样式的分段筛选，`swipeActions`，`contextMenu` |
| 详情 | `Form` 或分组 `List`，图片用翻页容器，全屏用 `fullScreenCover` |
| 新建 / 编辑 | `sheet` 里的 `NavigationStack` + `Form`，工具栏「取消」「存储」 |
| 模块、子题型、标签 | `Picker`，标签用可多选的列表 |
| 扫描 | iPhone / iPad：VisionKit 文稿扫描仪 |
| 拍照 | 系统相机 |
| 相册 | PhotosUI 照片选择器 |
| 文件 | `fileImporter`，限图片 |
| 确认丢弃、确认删除 | `confirmationDialog` 或 `alert` |
| 识别中 | `ProgressView` |

主要图标：

- 言语理解：`text.book.closed`
- 判断推理：`point.topleft.down.to.point.bottomright.curvepath`
- 数量关系：`function`
- 资料分析：`chart.bar.xaxis`
- 扫描：`document.viewfinder`
- 拍照：`camera`
- 相册：`photo.on.rectangle`
- 未掌握：`circle`；已掌握：`checkmark.circle`

若某个符号在目标系统上不可用，换成含义相同、系统里一定存在的符号，不使用自定义图标字体。

### 9.1 新建表单结构

```text
新建错题
├── 归属
│   ├── 模块
│   └── 子题型（选填）
├── 题目
│   ├── 页面缩略图（可排序、可删）
│   ├── 扫描文稿 / 拍照 / 相册或文件
│   └── 题目文字（可编辑）
├── 错因
│   ├── 页面缩略图
│   ├── 同样的三个收录按钮
│   ├── 错因文字（可编辑）
│   └── 错因标签
└── 状态
    └── 未掌握 / 已掌握
```

从某个模块进入时，「归属」仍可见，避免扫完才发现进错模块。

## 10. 平台差异

文稿扫描仪只在 iPhone 和 iPad 上提供。

| 能力 | iPhone | iPad | Mac | visionOS |
| --- | --- | --- | --- | --- |
| 四个模块、列表、详情、搜索、编辑、删除 | 完整 | 完整，侧边栏 | 完整，侧边栏 | 与 iPad 相同的栈式布局即可 |
| 文稿扫描 | 有 | 有 | 无。收录菜单不显示「扫描文稿」 | 无 |
| 拍照 | 有 | 有 | 通过系统连续互通相机拍照、或选文件 | 选文件、选已有图片 |
| 相册 / 文件 | 有 | 有 | 有 | 有 |
| 文字识别 | 有 | 有 | 有 | 有 |

Mac 上把「扫描文稿」换成说明：用 iPhone 扫描后从相册选入，或直接选择图片文件。不在 Mac 上模拟一套纸边扫描。

第一版以 iPhone 竖屏为验收基准。iPad 横屏须能用侧边栏完成同一条路径。

## 11. 数据与权限

### 11.1 存放

- 元数据用 SwiftData，存在本机。
- 图片写成文件，放在 App 支持目录下，按错题分开文件夹。数据库里只记相对路径、页序、这一页属于题目还是错因、这一页的识别文字。
- 删除错题时同时删除它的图片文件。
- 不上传任何图片或文字。

建议的模型划分：

- `WrongQuestion`：模块、子题型、题目文字、错因文字、标签、掌握状态、创建与修改时间。
- `ScanPage`：所属错题、题目或错因、顺序、图片相对路径、该页识别文字。

模块、掌握状态、页面种类用枚举的稳定原始值存储，便于以后迁移。界面文案和存储值分开。

### 11.2 权限文案

- 相机：用于扫描文稿和拍摄错题、错因。
- 不申请完整照片库权限。选图走系统选择器。
- 用户拒绝相机后，扫描和拍照按钮仍在，点按后说明可以到「设置」里打开相机，或改用相册和文件。已收录的内容保持可看。

### 11.3 图片

- 保存扫描件时压成 JPEG，长边不超过 2000 像素，兼顾看清印刷体和占用。
- 原比例保留，不裁成正方形。
- 列表缩略图由原图生成，不另要求用户上传封面。

## 13. 验收标准

用 iPhone 模拟器或真机走完。扫描仪和相机在模拟器上不可用时，用相册选图验收收录和识别，并在真机补扫一张纸。

1. 打开 App，能看到四个模块，每个模块的未掌握数量一开始是 0。
2. 进入「数量关系」，用相册放入一张含中文印刷体的题目图。题目文字出现在表单里，并且可以改。
3. 不添加错因页面、也不写错因文字时，无法存储。
4. 写上一句错因或再放入一张错因图后，可以存储。回到列表能看到这道题，模块计数变为 1。
5. 详情里题目图和错因图分开展示，文字与存储前一致。
6. 把状态改为已掌握后，列表分段「未掌握」里不再出现它，「已掌握」里出现。重启 App 后状态还在。
7. 搜索这道题里改过的一个词，能找到它。搜索一个不存在的词，得到空状态。
8. 给它加上「计算错误」，按这个标签筛选时只留下带该标签的题。
9. 编辑时可以删掉一页、调整页序、改文字，存储后详情更新。
10. 删除后列表消失，重启后仍然没有，对应图片文件也没有留下。
11. 四个模块彼此独立：在「言语理解」里看不到刚才那道数量关系题；「全部错题」里看得到。
12. iPad 横屏能从侧边栏进入任一模块并打开详情。
13. 界面在深色模式和较大动态字体下，主要路径不重叠、不截断到无法操作。
14. 不出现账号、网络上传、自动错因、复习推送的入口。

## 14. 实现时的工程约束

- 语言 Swift，界面 SwiftUI。扫描器用 VisionKit 包一层。文字识别用 Vision，在本机完成。选图用 PhotosUI。
- 不引入第三方 UI 库。
- 现有 `MyApp` 入口改为挂上数据容器和根界面。不保留 “Hello, world” 和 Playground 示例。
- 权限说明写进目标的 Info 配置。
- 代码按「数据、收录、列表与详情」分开，避免把扫描和界面堆进一个文件。
- 第一版界面文案使用简体中文。
